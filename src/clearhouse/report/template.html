Every issue the pipeline logs has a severity:

Error
the order can't be trusted, so it goes to quarantine
Warning
something was wrong, but the order is still usable: the value was repaired, or dropped because the order can do without it, and the issue log keeps the original
Info
worth knowing, nothing to fix

The full detail is in the CSV files written next to this report: orders, lines, customers, quarantine, duplicates and issues.
